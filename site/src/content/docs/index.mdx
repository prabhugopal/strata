## What you write

```java
@Entity(mount = "/orders/{id}", expose = true)
public class Order {
    private Status status = Status.NEW;          // state: plain fields
    @Inject Payments payments;                   // the outside world: only through services
    @Inject Ctx ctx;                             // time, randomness, identity

    @Command public String pay(String card) throws Declined {
        String receipt = payments.charge(ctx.entityId(), total, card);   // made exactly once
        status = Status.PAID;
        return receipt;
    }
}
```

No main class, no wiring, no retry code. Strata generates the HTTP routes and a typed client,
spreads entities over a [Pekko](https://pekko.apache.org) cluster, commits state before every
reply, and records every service call so an interrupted command resumes where it was.
