{/* Generated by site/scripts/reference.mjs from `strata --help`. */}

Install it with `cargo install --path cli/strata-cli` from the repository. Servers are kept in
`~/.strata/config.toml` (or `$STRATA_HOME`), readable only by you; tokens are read from stdin
(`--token-stdin`) or `STRATA_TOKEN`, never from arguments.

```text
Inspect and drive Strata nodes

Usage: strata [OPTIONS] <COMMAND>

Commands:
  server    Manage the servers this CLI knows (kept in ~/.strata/config.toml)
  info      The node: version, store, uptime
  cluster   Cluster members and where entities live
  types     Entity types and their commands
  entities  Entities of a type (stored and in memory)
  get       An entity's committed state: TYPE/ID
  call      Run a command: TYPE/ID COMMAND [ARG]. ARG is JSON (a bare word is sent as a string); use - to read it from stdin
  events    Recent events on the node
  metrics   Metrics: per-command totals, or the raw Prometheus text with --raw
  help      Print this message or the help of the given subcommand(s)

Options:
  -s, --server <SERVER>  Server to talk to (a name from `strata server list`); defaults to the one set with `server use` [env: STRATA_SERVER=]
      --url <URL>        Talk to this URL directly instead of a named server (token from STRATA_TOKEN) [env: STRATA_URL=]
  -F, --format <FORMAT>  Output format [default: text] [possible values: text, json]
  -h, --help             Print help
  -V, --version          Print version
```
