<Steps>

1. **Apply the plugin.** It adds Strata's modules, the annotation processor and the JVM flags
   Strata needs. Strata runs on Java 21 or newer.

   ```kotlin title="build.gradle.kts"
   plugins {
       java
       application
       id("io.github.strata-jvm.strata") version "0.1.0"
   }
   ```

2. **Write an entity.** Fields are the state; `@Command` methods change it, `@Query` methods read it.

   ```java title="src/main/java/demo/Counter.java"
   @Entity(mount = "/counters/{id}", expose = true)
   public class Counter {
       private long count;

       @Command public long increment() { return ++count; }
       @Query   public long count()     { return count; }
   }
   ```

3. **Run it.** There's no main class to write: the plugin runs Strata's own.

   ```sh
   ./gradlew run --args="--strata.store.kind=memory"
   curl -X POST localhost:8080/counters/alice/increment   # 1
   curl localhost:8080/counters/alice/count               # 1
   ```

4. **Keep it.** With `strata.store.kind = jdbc` (H2 by default, PostgreSQL via `STRATA_JDBC_URL`),
   stop the process however you like, start it again, and `alice` is still at 1.

</Steps>

## Other build tools

Every build tool reads Maven Central, so Strata's libraries work in all of them. The Gradle
plugin does the setup for you; elsewhere, add the runtime and the annotation processor (Java and
Kotlin entities; Scala and Clojure don't need it), and pass the JVM flags Strata needs
(`strata.jvm.args` in [gradle.properties](https://github.com/strata-jvm/strata/blob/main/gradle.properties))
when you run.

<Tabs syncKey="build">
<TabItem label="Maven">

```xml
<dependencies>
  <dependency>
    <groupId>io.github.strata-jvm</groupId>
    <artifactId>strata-pekko</artifactId>
    <version>0.1.0</version>
  </dependency>
</dependencies>
<build><plugins><plugin>
  <artifactId>maven-compiler-plugin</artifactId>
  <configuration>
    <annotationProcessorPaths>
      <path>
        <groupId>io.github.strata-jvm</groupId>
        <artifactId>strata-processor</artifactId>
        <version>0.1.0</version>
      </path>
    </annotationProcessorPaths>
  </configuration>
</plugin></plugins></build>
```

</TabItem>
<TabItem label="sbt">

```scala
libraryDependencies += "io.github.strata-jvm" % "strata-pekko" % "0.1.0"
```

</TabItem>
<TabItem label="Leiningen">

```clojure
:dependencies [[io.github.strata-jvm/strata-clojure "0.1.0"]
               [io.github.strata-jvm/strata-pekko "0.1.0"]]
```

</TabItem>
<TabItem label="deps.edn">

```clojure
{:deps {io.github.strata-jvm/strata-clojure {:mvn/version "0.1.0"}
        io.github.strata-jvm/strata-pekko   {:mvn/version "0.1.0"}}}
```

</TabItem>
</Tabs>
